Database
  If MONGO_URI is empty, the API uses an embedded MongoDB that resets when the process stops.
  For a persistent database set MONGO_URI=mongodb://127.0.0.1:27017/eventsphere
  Database name: eventsphere
  There is no separate database password in the local setup.
  A data backup without password hashes is written to docs/database/eventsphere-backup.json
